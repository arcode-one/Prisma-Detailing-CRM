# Prisma Detailing — CRM детейлинг-центра (демо для портфолио)

PWA для записи машин в детейлинг-центр: записи на день с календарём и сменами мастеров, умная форма с автоподбором клиента по марке, номеру и телефону, справочник клиентов с историей визитов, способ оплаты (наличные / карта / перевод) с разбивкой выручки за день и месяц, чёрный список, корзина отменённых записей, архив по месяцам с выгрузкой в Excel, список услуг с ценами. Работает на телефоне (ставится на главный экран) и на ПК.

> **Это демо-версия.** Все клиенты, номера и телефоны вымышленные. Сервера нет — данные хранятся в `localStorage` браузера, их можно свободно добавлять, менять и удалять. Кнопка «Сбросить демо-данные» (в боковом меню на ПК и в разделе «Услуги» на телефоне) возвращает всё к исходному состоянию.

## Вход

| Роль | Логин | Пароль | Что может |
|---|---|---|---|
| Администратор | `admin` | `demo` | всё |
| Мастер | `master` | `demo` | записи и ЧС; справочник только смотрит, корзину не чистит |

## Стек

Vite · React 19 · TypeScript · Tailwind CSS v4 · TanStack Query (с кешем в localStorage) · React Router · vite-plugin-pwa · SheetJS (выгрузка в Excel).

В боевой версии данные лежат в Supabase (Postgres + Auth + Realtime, права через RLS). В демо серверная логика перенесена в [`src/lib/demoDb.ts`](src/lib/demoDb.ts):

- привязка записи к существующей машине (марка/модель + номер, без номера — телефон);
- новый клиент попадает в справочник после окончания дня;
- пересчёт «последней услуги / цены / числа визитов» у клиента;
- чёрный список: занести может мастер, убрать — только админ;
- отмена записи → корзина, очистка корзины — только админ;
- синхронизация между вкладками браузера (аналог Realtime).

Демо-данные (≈8 месяцев истории, ~70 машин, 13 услуг) генерируются относительно сегодняшней даты. Пока вы ничего не меняли, они пересоздаются каждый день, чтобы «сегодня» всегда было заполнено.

## Запуск

```bash
npm install
npm run dev
```

Сборка — `npm run build`, папка `dist` готова к выкладке на любой статический хостинг (Vercel, Cloudflare Pages, Netlify). Иконки и splash-экраны: `npm run assets`.
